      What Mode, Status and Health show

      They are read live over Bluetooth, from the station's radio chip. They describe what the radio reports, which isn't always what the station is actually doing.

      • Mode matches the station's channel on radio firmware 2.x. On radio firmware 1.1 (R: 1.1…) it shows a leftover value (e.g. 234); the station still transmits on its correct channel.
      • Status "Not set since boot" (radio firmware 1.1 and 2.2): the radio hasn't been told a power state since the station powered up. The station is running; sending Wake or Sleep once gives a real status.
      • Health (experimental) is the faults field of the station's info block, 0 on a healthy station. Fault shows the raw value; the individual bits aren't documented. Radio firmware 1.1 doesn't report it (–).
      • Identify blinks the station's LED. Not supported on radio firmware 1.1.
      Pairing, browsers and backup

      Browsers only let a page talk to Bluetooth devices you picked for it. Use Add station to pick a new one, or Pair on a registered station to pick that exact station. Browsers that remember your picks show paired stations straight away next time; others ask again after a reload.

      • iPhone / iPad: Safari can't use Bluetooth. Open this page in the free Bluefy browser.
      • Android, Windows, macOS, ChromeOS: Chrome or Edge.
      • Linux: Chrome, with chrome://flags/#enable-experimental-web-platform-features enabled.

      Names are saved in this browser only, as a name → station ID list in the same format as the desktop tool's stations.json. Export it to move it to another device or back it up.
